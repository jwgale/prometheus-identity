## 2. What lives on the issuer record

The issuer record is the only place for:

- the current Module-Lattice Digital Signature Algorithm public key
- trusted member public keys
- previous issuer keys with a kill date
- accepted issuer public keys
- accepted previous issuer keys with a kill date
- accepted sealed issuer keys with the store-wide kill date
- the laboratory Biscuit envelope public key
- the cryptographic profile
- threshold_n (issuance)
- verify_threshold_n (foreign verify)
- an optional store-wide kill date

The Biscuit envelope key is not a threshold member. The Biscuit token is a laboratory envelope. The Biscuit token is not the identity root. The Biscuit token is not a second kernel.

Member secrets, holder secrets, and the Biscuit envelope secret are operator files. They are not identity records.

Issuer-key transparency is already refused. Rotate cannot drop a previous public key. A wrap or act signed only by a previous key past its kill date is refused on the issuing store.
