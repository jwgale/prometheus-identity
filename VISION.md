## 1. The bet

Today’s identity provider is five later steps. A directory creates a name. A login proves a human. Groups or roles grant authorization after login. A review governs that grant. A vault or a privileged path holds a standing secret.

An agent cannot attest intent the way a human can. That stack fails at birth. The later ecosystem around that stack (a directory connector, an access-review product, a secrets broker, a workload identity mesh that mints a name) assumes the same order.

Prometheus inverts the order.

1. One write at birth holds the principal, the owner, the intent-scoped capability, and the death path.
2. Present is a document of one act. A second party verifies the document. A second party does not look up a name and enumerate groups.
3. Kill is portable death. A verifier accepts a signed death bundle. The verifier does not copy the inode.
4. Spawn writes a narrower child of that act. Spawn is not a role catalog.
5. X.509 and SPIFFE are a presentation on-ramp. The instance identifier is not a distinguished name. Short life is not kill.

A later study of human identity may use this model after an agent platform is adopted. That study is not this laboratory. Do not plan the human identity provider replacement in this tree.

## 2. Layers

Map each slice to the kernel story and to a layer.

Kernel story: an agent is born, the agent can present, a consumer can check that present, the agent can die.

Layers:

1. inode — the five records (agent type, instance, capability, chain, issuer). A sixth identity record is refused.
2. envelope — the laboratory Biscuit token. The identity root is Module-Lattice Digital Signature Algorithm. The envelope is not the inode.
3. artifact — presentation, decision receipt, Merkle proof, signed tree head, act bundle, kill bundle, laboratory X.509-SVID wrap. Artifacts are not records.
4. on-ramp — SPIFFE X.509-SVID now. WIMSE HTTP token plus Content-Digest started. Transaction Tokens only inside one domain.

Operator verbs sit on the five system calls. See PROVISION.md. Anatomy and the refuse list live in ANATOMY.md.
